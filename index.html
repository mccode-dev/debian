McCode apt repository

Debian and Ubuntu packages of McStas and McXtrace for amd64 and arm64, as built by the McCode release workflows. The packages are stored as assets of the apt release of mccode-dev/mccode-apt.

Set up

sudo curl -fsSL https://mccode-dev.github.io/mccode-apt/mccode-apt.gpg -o /usr/share/keyrings/mccode-apt.gpg
echo "deb [signed-by=/usr/share/keyrings/mccode-apt.gpg] https://github.com/mccode-dev/mccode-apt/releases/download/apt/ ./" \
  | sudo tee /etc/apt/sources.list.d/mccode.list
sudo apt update

Install

sudo apt install mcstas-suite-python     # McStas
sudo apt install mcxtrace-suite-python   # McXtrace

The newest release is installed by default; apt-cache policy mcstas lists the versions in the repository.

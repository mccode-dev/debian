McCode apt repository

Debian and Ubuntu packages of McStas and McXtrace for amd64 and arm64, as built by the McCode release workflows, plus cif2hkl from SOLEIL. The packages are stored as assets of the apt release of mccode-dev/debian.

Set up

sudo wget -O /usr/share/keyrings/mccode-apt.gpg https://mccode-dev.github.io/debian/mccode-apt.gpg
cd /etc/apt/sources.list.d
sudo rm -f mccode.list   # older one-line format, replaced by mccode.sources
sudo wget -O mccode.sources https://mccode-dev.github.io/debian/mccode.sources
sudo apt-get update

Install

sudo apt install mcstas-suite-python     # McStas
sudo apt install mcxtrace-suite-python   # McXtrace

The newest release is installed by default; apt-cache policy mcstas lists the versions in the repository.

Legacy releases

The final McStas 2.x (2.7.2) and McXtrace 1.x (1.7.1) install side by side with 3.x:

sudo apt install mcstas-suite-python-legacy    # or mcstas-suite-perl-legacy
sudo apt install mcxtrace-suite-python-legacy  # or mcxtrace-suite-perl-legacy

Start a shell for them with mcstas-2.7.2-environment or mcxtrace-1.7.1-environment. The Perl tools need pgplot5 from Ubuntu's multiverse component (Debian: non-free).
